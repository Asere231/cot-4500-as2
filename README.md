# Polynomial Interpolation Assignment (COT-4500-as2)
This project implements various polynomial interpolation methods including Neville's method, Newton's forward difference, Hermite interpolation, and cubic spline interpolation.
Requirements

Python 3.8+
NumPy

Install requirements using:
```bash pip install -r requirements.txt```

Project Structure:

|   |   |-- __init__.py
|   |   |-- assignment_2.py
|   |-- test/
|   |   |-- __init__.py
|   |   |-- test_assignment_2.py
|-- requirements.txt
|-- README.md

# Running the Program
To run the main program:
```bash python src/main/assignment_2.py```

To run the tests:
```bash python -m unittest src/test/test_assignment_2.py```

# Implementation Details
The program implements the following methods:

Neville's method for polynomial interpolation
Newton's forward difference method
Newton interpolation
Hermite interpolation
Cubic spline interpolation

Each method is implemented in its own function with appropriate documentation and test cases.
